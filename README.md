# suivi-scholaire-plus
Suivi Scolaire Plus est une application web conçue pour faciliter le suivi académique des élèves par leurs parents. Développé initialement à l'occasion de la journée portes ouvertes en Terminale TI (Technologies de l'Information) au Lycée Classique de Foumban, ce projet répond à une problématique concrète d'accès à l'information scolaire.
